# 背景

在使用AI Agent时，你是否困惑过，应该选择什么环境、什么形态的 Agent 终端？以 Codex 为例，有 Desktop App （https://chatgpt.com/zh-Hans-CN/codex/），也有 CLI工具（https://github.com/openai/codex）。以及，如果使用的是Windows环境，例如我，还面临着PS7、WSL2的选择。

根据奥卡姆剃刀原理，如非必要，勿增实体。对于同一类需求，当存在多种工具可以选择，并且这些工具的功能相近时，我倾向于只选其中最适合那一个。尤其是AI Agent这一类工具，要使用的不仅是工具本身，还有大量定制的配置项、Skill、MCP等。更何况，这些配置项等并不是静态的，它们也会发生版本更新、迭代。如果在一台电脑上使用两种Agent终端，难免会面临着重复配置、重复安装Skill等问题。
